# Empire Clash

A superhero strategy board game for mobile. Seven original heroes roll the dice, capture districts and fight timing-based Clashes for control of Nova City.

**Play:** https://juanmmesa3d.github.io/score-player/empire-clash/

- 7 heroes, each with a passive and 3 abilities
- 20-tile isometric board with Outposts, Towers and HQs
- Empire Clash timing duel, AI rivals, 8-round matches

Characters, concept art and game design by Juan Mesa. Built with Claude.
